# Feature Showcase

A marketing section where opening an accordion item changes the image beside it.

## Exports

`Feature`

Props are typed in `index.tsx`. See `demos/` for a complete example.

## Changes from the Kibo block

`features` is required, and the sample content and hosted images were removed. Item `id` values are now strings.

## Origin

From [Kibo UI](https://www.kibo-ui.com) (MIT). Copy this folder with the `use-component` skill, which also installs its dependencies.
