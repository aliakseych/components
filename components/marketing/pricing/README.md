# Pricing Tiers

Only the pricing plan cards, with animated prices and a highlighted plan.

## Exports

`PricingTiers`

Props are typed in `index.tsx`. See `demos/` for a complete example.

## Changes from the Kibo block

This keeps only the tier cards, as requested. There is no page heading or billing toggle, so control the period with the `frequency` prop. `plans` is required, and each plan can take an `onSelect` handler.

## Origin

From [Kibo UI](https://www.kibo-ui.com) (MIT). Copy this folder with the `use-component` skill, which also installs its dependencies.
