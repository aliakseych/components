# Data Table: Pagination

Recent orders, five to a page.

```tsx
import { DataTable5, dataTable5ExampleProps } from "./data-table-05";

<DataTable5 {...dataTable5ExampleProps} />;
```

`dataTable5ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `DataTable5Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/data-table-05
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/data-table/`.
