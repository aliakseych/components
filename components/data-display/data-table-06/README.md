# Data Table: Full Featured

Search, filters with counts, a column menu, page sizes, multi-column sorting and selected rows to export or email.

```tsx
import { DataTable6, dataTable6ExampleProps } from "./data-table-06";

<DataTable6 {...dataTable6ExampleProps} />;
```

`dataTable6ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `DataTable6Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/data-table-06
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/data-table/`.
