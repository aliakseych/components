# Data Table: Trends

Campaign conversions and cost per conversion with their change, plus a 14-day sparkline.

```tsx
import { DataTable3, dataTable3ExampleProps } from "./data-table-03";

<DataTable3 {...dataTable3ExampleProps} />;
```

`dataTable3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `DataTable3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/data-table-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/data-table/`.
