# Data Table: Status

Services with their status, latency and error rate, worst status first.

```tsx
import { DataTable4, dataTable4ExampleProps } from "./data-table-04";

<DataTable4 {...dataTable4ExampleProps} />;
```

`dataTable4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `DataTable4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/data-table-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/data-table/`.
