# Leaderboard: Rank Movement

Products ranked by revenue, with how many places each moved and the biggest climber named.

```tsx
import { Leaderboard4, leaderboard4ExampleProps } from "./leaderboard-04";

<Leaderboard4 {...leaderboard4ExampleProps} />;
```

`leaderboard4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Leaderboard4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/leaderboard-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/leaderboard/`.
