# KPI: Compact

A value with its change written beside the label, for a tight grid of KPIs.

```tsx
import { KPI2, kpi2ExampleProps } from "./kpi-02";

<KPI2 {...kpi2ExampleProps} />;
```

`kpi2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `KPI2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/kpi-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/kpi/`.
