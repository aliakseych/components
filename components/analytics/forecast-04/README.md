# Forecast: Scenarios

Low, base and high growth scenarios from the last actual, as a chart and a table with when each one reaches the target.

```tsx
import { Forecast4, forecast4ExampleProps } from "./forecast-04";

<Forecast4 {...forecast4ExampleProps} />;
```

`forecast4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Forecast4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/forecast-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/forecast/`.
