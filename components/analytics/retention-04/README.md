# Retention: Growth Accounting

Users gained above the axis and lost below it, with the net change and the quick ratio of users gained for each one lost.

```tsx
import { Retention4, retention4ExampleProps } from "./retention-04";

<Retention4 {...retention4ExampleProps} />;
```

`retention4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Retention4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/retention-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/retention/`.
