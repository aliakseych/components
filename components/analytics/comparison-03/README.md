# Comparison: What Changed

The net change, then the change in each segment as bars either side of zero, from the biggest gain to the biggest drop.

```tsx
import { Comparison3, comparison3ExampleProps } from "./comparison-03";

<Comparison3 {...comparison3ExampleProps} />;
```

`comparison3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Comparison3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/comparison-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/comparison/`.
