# Comparison: Period over Period

Each metric this period and last, with the difference and the change, under a sentence saying how many improved.

```tsx
import { Comparison1, comparison1ExampleProps } from "./comparison-01";

<Comparison1 {...comparison1ExampleProps} />;
```

`comparison1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Comparison1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/comparison-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/comparison/`.
