# Leaderboard: Podium

The top three on a podium sized by their totals, with the rest of the field listed below.

```tsx
import { Leaderboard3, leaderboard3ExampleProps } from "./leaderboard-03";

<Leaderboard3 {...leaderboard3ExampleProps} />;
```

`leaderboard3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Leaderboard3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/leaderboard-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/leaderboard/`.
