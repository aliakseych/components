# Scatter: Risk Matrix

Open risks on a likelihood by impact grid, with a cell's risks listed when you select it.

```tsx
import { Scatter4, scatter4ExampleProps } from "./scatter-04";

<Scatter4 {...scatter4ExampleProps} />;
```

`scatter4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Scatter4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/scatter-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/scatter/`.
