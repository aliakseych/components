# Feedback: Recent Reviews

The latest reviews with their rating and source, and whether low ratings still need a reply.

```tsx
import { Feedback3, feedback3ExampleProps } from "./feedback-03";

<Feedback3 {...feedback3ExampleProps} />;
```

`feedback3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Feedback3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/feedback-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/feedback/`.
