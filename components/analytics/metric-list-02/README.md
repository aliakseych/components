# Metric List: Sections

Metrics grouped into sections, each with a header and how many of its metrics improved.

```tsx
import { MetricList2, metricList2ExampleProps } from "./metric-list-02";

<MetricList2 {...metricList2ExampleProps} />;
```

`metricList2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `MetricList2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/metric-list-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/metric-list/`.
