# Goals: Projection

Cumulative progress this month, projected to the end of the month, with the day it reaches the target or how far short it ends.

```tsx
import { Goals3, goals3ExampleProps } from "./goals-03";

<Goals3 {...goals3ExampleProps} />;
```

`goals3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Goals3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/goals-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/goals/`.
