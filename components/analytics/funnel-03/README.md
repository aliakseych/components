# Funnel: Steps

A vertical stepper that names the step with the biggest drop-off.

```tsx
import { Funnel3, funnel3ExampleProps } from "./funnel-03";

<Funnel3 {...funnel3ExampleProps} />;
```

`funnel3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Funnel3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/funnel-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/funnel/`.
