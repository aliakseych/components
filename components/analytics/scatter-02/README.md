# Scatter: Quadrants

Features by usage and satisfaction, split at the medians into four labelled quadrants.

```tsx
import { Scatter2, scatter2ExampleProps } from "./scatter-02";

<Scatter2 {...scatter2ExampleProps} />;
```

`scatter2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Scatter2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/scatter-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/scatter/`.
