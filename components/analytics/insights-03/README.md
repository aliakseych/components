# Insights: Key Drivers

What contributed to a change, as bars either side of zero, under a sentence naming the biggest driver and drag.

```tsx
import { Insights3, insights3ExampleProps } from "./insights-03";

<Insights3 {...insights3ExampleProps} />;
```

`insights3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Insights3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/insights-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/insights/`.
