# Flow: Top Paths

The most common routes as steps, ranked by how many took them, with how often each reaches the goal.

```tsx
import { Flow4, flow4ExampleProps } from "./flow-04";

<Flow4 {...flow4ExampleProps} />;
```

`flow4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Flow4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/flow-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/flow/`.
