# Feedback: Sentiment by Topic

Negative and positive mentions either side of a centre line for each topic, sorted by net sentiment.

```tsx
import { Feedback2, feedback2ExampleProps } from "./feedback-02";

<Feedback2 {...feedback2ExampleProps} />;
```

`feedback2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Feedback2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/feedback-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/feedback/`.
