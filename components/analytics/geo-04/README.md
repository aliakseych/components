# Geo: Region Split

Revenue split across regions, each with its share and change on the previous quarter.

```tsx
import { Geo4, geo4ExampleProps } from "./geo-04";

<Geo4 {...geo4ExampleProps} />;
```

`geo4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Geo4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/geo-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/geo/`.
