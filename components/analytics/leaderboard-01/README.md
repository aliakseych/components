# Leaderboard: Share Bars

Ranked rows with a bar sized relative to the leader, and how much of the traffic the top page drew.

```tsx
import { Leaderboard1, leaderboard1ExampleProps } from "./leaderboard-01";

<Leaderboard1 {...leaderboard1ExampleProps} />;
```

`leaderboard1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Leaderboard1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/leaderboard-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/leaderboard/`.
