# Metric List: Targets

Metrics against their targets, floors or ceilings, each with a bar, a tick at the target and a status.

```tsx
import { MetricList3, metricList3ExampleProps } from "./metric-list-03";

<MetricList3 {...metricList3ExampleProps} />;
```

`metricList3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `MetricList3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/metric-list-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/metric-list/`.
