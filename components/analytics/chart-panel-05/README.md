# Chart Panel: Breakdown Donut

Part-to-whole at a glance, with values and shares listed beside the donut.

```tsx
import { ChartPanel5, chartPanel5ExampleProps } from "./chart-panel-05";

<ChartPanel5 {...chartPanel5ExampleProps} />;
```

`chartPanel5ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `ChartPanel5Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/chart-panel-05
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/chart-panel/`.
