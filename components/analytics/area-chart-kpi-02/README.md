# KPI: Background Chart

A large total with an area chart along the bottom, for the hero number at the top of a dashboard.

```tsx
import { AreaChartKPI2, areaChartKpi2ExampleProps } from "./area-chart-kpi-02";

<AreaChartKPI2 {...areaChartKpi2ExampleProps} />;
```

`areaChartKpi2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `AreaChartKPI2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/area-chart-kpi-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/kpi/`.
