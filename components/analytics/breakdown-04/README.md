# Breakdown: Share Shift

How each category's share moved between two periods, as two dots joined by a line.

```tsx
import { Breakdown4, breakdown4ExampleProps } from "./breakdown-04";

<Breakdown4 {...breakdown4ExampleProps} />;
```

`breakdown4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Breakdown4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/breakdown-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/breakdown/`.
