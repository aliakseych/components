# Stat Group: Metric Tabs

Metrics as tabs, with the selected one charted by day over the previous period.

```tsx
import { StatGroup3, statGroup3ExampleProps } from "./stat-group-03";

<StatGroup3 {...statGroup3ExampleProps} />;
```

`statGroup3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `StatGroup3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/stat-group-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/stat-group/`.
