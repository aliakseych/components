# Distribution: Before and After

This week's distribution against last week's, with both medians and the change at the median and p90.

```tsx
import { Distribution4, distribution4ExampleProps } from "./distribution-04";

<Distribution4 {...distribution4ExampleProps} />;
```

`distribution4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Distribution4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/distribution-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/distribution/`.
