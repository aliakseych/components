# Breakdown: Composition by Group

The mix across groups, sorted by one category's share, which is labelled on every row.

```tsx
import { Breakdown2, breakdown2ExampleProps } from "./breakdown-02";

<Breakdown2 {...breakdown2ExampleProps} />;
```

`breakdown2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Breakdown2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/breakdown-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/breakdown/`.
