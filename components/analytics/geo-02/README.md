# Geo: Top Countries

The leading countries with flags, values and shares, and the rest summed into one row.

```tsx
import { Geo2, geo2ExampleProps } from "./geo-02";

<Geo2 {...geo2ExampleProps} />;
```

`geo2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Geo2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/geo-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/geo/`.
