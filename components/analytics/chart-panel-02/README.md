# Chart Panel: Metric Tabs

Related metrics as tabs, each with its total and change, and the chosen metric's average marked on the chart.

```tsx
import { ChartPanel2, chartPanel2ExampleProps } from "./chart-panel-02";

<ChartPanel2 {...chartPanel2ExampleProps} />;
```

`chartPanel2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `ChartPanel2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/chart-panel-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/chart-panel/`.
