# Leaderboard: Sortable

A ranking you can reverse and expand to show every entry.

```tsx
import { Leaderboard5, leaderboard5ExampleProps } from "./leaderboard-05";

<Leaderboard5 {...leaderboard5ExampleProps} />;
```

`leaderboard5ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Leaderboard5Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/leaderboard-05
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/leaderboard/`.
