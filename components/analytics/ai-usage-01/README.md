# AI Usage: Token Usage

Tokens per day stacked by model against the daily average, with the total cost and the cost per million tokens.

```tsx
import { AiUsage1, aiUsage1ExampleProps } from "./ai-usage-01";

<AiUsage1 {...aiUsage1ExampleProps} />;
```

`aiUsage1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `AiUsage1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/ai-usage-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/ai-usage/`.
