# Insights: Feed

A list of insights, each with its kind, topic, sentence, an optional line of drivers and a link to explore.

```tsx
import { Insights1, insights1ExampleProps } from "./insights-01";

<Insights1 {...insights1ExampleProps} />;
```

`insights1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Insights1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/insights-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/insights/`.
