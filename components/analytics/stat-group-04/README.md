# Stat Group: Compact Strip

Five metrics in a slim row.

```tsx
import { StatGroup4, statGroup4ExampleProps } from "./stat-group-04";

<StatGroup4 {...statGroup4ExampleProps} />;
```

`statGroup4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `StatGroup4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/stat-group-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/stat-group/`.
