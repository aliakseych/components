# Scatter: Bubbles

Campaigns by cost per acquisition and conversion rate, sized by spend and coloured by channel, against a target cost.

```tsx
import { Scatter3, scatter3ExampleProps } from "./scatter-03";

<Scatter3 {...scatter3ExampleProps} />;
```

`scatter3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Scatter3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/scatter-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/scatter/`.
