# Heatmap: Cohort Retention

The share of each weekly signup cohort still active in each week after signup.

```tsx
import { Heatmap2, heatmap2ExampleProps } from "./heatmap-02";

<Heatmap2 {...heatmap2ExampleProps} />;
```

`heatmap2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Heatmap2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/heatmap-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/heatmap/`.
