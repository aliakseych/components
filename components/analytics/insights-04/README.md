# Insights: Weekly Digest

A headline, three takeaways and buttons to say whether it helped.

```tsx
import { Insights4, insights4ExampleProps } from "./insights-04";

<Insights4 {...insights4ExampleProps} />;
```

`insights4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Insights4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/insights-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/insights/`.
