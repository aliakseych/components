# Scatter: Correlation

Pages by load time and conversion rate, grouped by section, with a trend line and how strong the relationship is.

```tsx
import { Scatter1, scatter1ExampleProps } from "./scatter-01";

<Scatter1 {...scatter1ExampleProps} />;
```

`scatter1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Scatter1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/scatter-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/scatter/`.
