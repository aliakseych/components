# Feedback: Customer Satisfaction

Weekly CSAT against a target line, with the change on the week before and how many weeks met the target.

```tsx
import { Feedback4, feedback4ExampleProps } from "./feedback-04";

<Feedback4 {...feedback4ExampleProps} />;
```

`feedback4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Feedback4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/feedback-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/feedback/`.
