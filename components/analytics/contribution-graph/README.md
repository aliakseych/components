# Contribution Graph

A year-long activity heatmap with month labels, a total count and a legend.

## Exports

`ContributionGraph`, `ContributionGraphBlock`, `ContributionGraphCalendar`, `ContributionGraphFooter`, `ContributionGraphTotalCount`, `ContributionGraphLegend`

Props are typed in `index.tsx`. See `demos/` for a complete example.

## Origin

From [Kibo UI](https://www.kibo-ui.com) (MIT). Copy this folder with the `use-component` skill, which also installs its dependencies.
