# Metric List: Watchlist

A list of metrics beside a chart of the selected one against its 30-day average.

```tsx
import { MetricList4, metricList4ExampleProps } from "./metric-list-04";

<MetricList4 {...metricList4ExampleProps} />;
```

`metricList4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `MetricList4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/metric-list-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/metric-list/`.
