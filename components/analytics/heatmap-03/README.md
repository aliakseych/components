# Heatmap: Calendar

A year of daily values, with the busiest day and the longest run of active days.

```tsx
import { Heatmap3, heatmap3ExampleProps } from "./heatmap-03";

<Heatmap3 {...heatmap3ExampleProps} />;
```

`heatmap3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Heatmap3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/heatmap-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/heatmap/`.
