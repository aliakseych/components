# KPI: Row

A row of headline KPIs, each in its own card, for the top of a dashboard.

```tsx
import { KPI5, kpi5ExampleProps } from "./kpi-05";

<KPI5 {...kpi5ExampleProps} />;
```

`kpi5ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `KPI5Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/kpi-05
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/kpi/`.
