# Goals: Target

One target with where today's pace ends up and how much a day is left to do.

```tsx
import { Goals1, goals1ExampleProps } from "./goals-01";

<Goals1 {...goals1ExampleProps} />;
```

`goals1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Goals1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/goals-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/goals/`.
