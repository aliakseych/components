# Geo: Dotted World Map

Active users by city right now, with markers sized by value and the busiest city named on the map.

```tsx
import { Geo3, geo3ExampleProps } from "./geo-03";

<Geo3 {...geo3ExampleProps} />;
```

`geo3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Geo3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/geo-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/geo/`.
