# Feedback: Ratings

The average rating with stars, the number of ratings and the share of each star, with CSAT and the change on the last period.

```tsx
import { Feedback1, feedback1ExampleProps } from "./feedback-01";

<Feedback1 {...feedback1ExampleProps} />;
```

`feedback1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Feedback1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/feedback-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/feedback/`.
