# Goals: Goal List

Several goals for the same period, each with its own pace.

```tsx
import { Goals2, goals2ExampleProps } from "./goals-02";

<Goals2 {...goals2ExampleProps} />;
```

`goals2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Goals2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/goals-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/goals/`.
