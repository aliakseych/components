# KPI: Previous Value

A rate beside its previous value, with the change in percentage points.

```tsx
import { KPI3, kpi3ExampleProps } from "./kpi-03";

<KPI3 {...kpi3ExampleProps} />;
```

`kpi3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `KPI3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/kpi-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/kpi/`.
