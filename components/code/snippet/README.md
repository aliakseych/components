# Snippet

A compact command block with tabs, such as for package managers, and a copy button.

## Exports

`Snippet`, `SnippetHeader`, `SnippetCopyButton`, `SnippetTabsList`, `SnippetTabsTrigger`, `SnippetTabsContent`

Props are typed in `index.tsx`. See `demos/` for a complete example.

## Origin

From [Kibo UI](https://www.kibo-ui.com) (MIT). Copy this folder with the `use-component` skill, which also installs its dependencies.
