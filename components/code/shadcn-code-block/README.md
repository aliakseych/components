# Code Block (shadcn)

A lightweight code block with a title, copy button, optional line numbers and wrapping.

See `demos/default.tsx` for a complete example.

## Install in an app

This item isn't in the older `new-york` shadcn style. Use a newer style, or install from its URL with your `components.json` style set to `radix-nova`. It also adds `hooks/use-highlighted-code.ts` and `lib/highlighter.tsx`, and the generated files import `cn` from `@/lib/utils` here.

## Origin

From shadcn/ui.
