# Code Block

Code display with syntax highlighting, line numbers, tabs for several files, and a copy button.

## Exports

`CodeBlock`, `CodeBlockHeader`, `CodeBlockFiles`, `CodeBlockFilename`, `CodeBlockSelect`, `CodeBlockSelectTrigger`, `CodeBlockSelectValue`, `CodeBlockSelectContent`, `CodeBlockSelectItem`, `CodeBlockCopyButton`, `CodeBlockBody`, `CodeBlockItem`, `CodeBlockContent`

Props are typed in `index.tsx`. See `demos/` for a complete example.

## Caveats

`server.tsx` is for React Server Components. Use the client exports elsewhere.

## Origin

From [Kibo UI](https://www.kibo-ui.com) (MIT). Copy this folder with the `use-component` skill, which also installs its dependencies.
