# DashboardHeader: Dashboard Header

Last Updated: A description, the time of the last update and a refresh button, beside the date range and export.

```tsx
import { DashboardHeader4, dashboardHeader4ExampleProps } from "./dashboard-header-04";

<DashboardHeader4 {...dashboardHeader4ExampleProps} />;
```

`dashboardHeader4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `DashboardHeader4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/dashboard-header-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/dashboard-header/`.
