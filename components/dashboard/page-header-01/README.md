# Page Header: Actions

A title and description with a secondary and a main action.

```tsx
import { PageHeader1, pageHeader1ExampleProps } from "./page-header-01";

<PageHeader1 {...pageHeader1ExampleProps} />;
```

`pageHeader1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `PageHeader1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/page-header-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/page-header/`.
