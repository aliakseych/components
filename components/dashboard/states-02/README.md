# States: Refresh

A chart that stays in place, dimmed, while it refreshes.

```tsx
import { States2, states2ExampleProps } from "./states-02";

<States2 {...states2ExampleProps} />;
```

`states2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `States2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/states-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/states/`.
