# Page Header: List

The count beside the title, with search and the main action on the same row.

```tsx
import { PageHeader4, pageHeader4ExampleProps } from "./page-header-04";

<PageHeader4 {...pageHeader4ExampleProps} />;
```

`pageHeader4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `PageHeader4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/page-header-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/page-header/`.
