# Page Header: Record

A back link, a photo, the customer's key numbers in a row and a menu for less common actions.

```tsx
import { PageHeader3, pageHeader3ExampleProps } from "./page-header-03";

<PageHeader3 {...pageHeader3ExampleProps} />;
```

`pageHeader3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `PageHeader3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/page-header-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/page-header/`.
