# Page Header: Tabs

The status as a badge beside the title, and links to the page's sections with their counts.

```tsx
import { PageHeader2, pageHeader2ExampleProps } from "./page-header-02";

<PageHeader2 {...pageHeader2ExampleProps} />;
```

`pageHeader2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `PageHeader2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/page-header-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/page-header/`.
