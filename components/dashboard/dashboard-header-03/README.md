# DashboardHeader: Dashboard Header

Segmented Presets: Date range presets as a segmented control, with a compare switch and a filter tag.

```tsx
import { DashboardHeader3, dashboardHeader3ExampleProps } from "./dashboard-header-03";

<DashboardHeader3 {...dashboardHeader3ExampleProps} />;
```

`dashboardHeader3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `DashboardHeader3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/dashboard-header-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/dashboard-header/`.
