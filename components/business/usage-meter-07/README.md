# Usage Meter: Liquid Gauge

What's left as a liquid that drains as usage grows, turning orange and then red.

```tsx
import { UsageMeter7, usageMeter7ExampleProps } from "./usage-meter-07";

<UsageMeter7 {...usageMeter7ExampleProps} />;
```

`usageMeter7ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `UsageMeter7Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/usage-meter-07
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/usage-meter/`.
