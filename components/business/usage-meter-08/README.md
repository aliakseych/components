# Usage Meter: Liquid Ring

What's left as a round wave that drains as usage grows, with used, free and the days until reset below.

```tsx
import { UsageMeter8, usageMeter8ExampleProps } from "./usage-meter-08";

<UsageMeter8 {...usageMeter8ExampleProps} />;
```

`usageMeter8ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `UsageMeter8Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/usage-meter-08
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/usage-meter/`.
