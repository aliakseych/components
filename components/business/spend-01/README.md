# Spend: Monthly Budget

Spend so far against the month's budget, with the projected month end and what's left to spend per day.

```tsx
import { Spend1, spend1ExampleProps } from "./spend-01";

<Spend1 {...spend1ExampleProps} />;
```

`spend1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Spend1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/spend-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/spend/`.
