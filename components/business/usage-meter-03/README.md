# Usage Meter: Metered Billing

The estimated overage, then usage against what the plan includes for each meter, with what each overage costs.

```tsx
import { UsageMeter3, usageMeter3ExampleProps } from "./usage-meter-03";

<UsageMeter3 {...usageMeter3ExampleProps} />;
```

`usageMeter3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `UsageMeter3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/usage-meter-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/usage-meter/`.
