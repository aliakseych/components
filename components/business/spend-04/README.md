# Spend: Burn and Runway

The cash balance, the average net burn and the months of runway left, with the balance projected to the month it runs out.

```tsx
import { Spend4, spend4ExampleProps } from "./spend-04";

<Spend4 {...spend4ExampleProps} />;
```

`spend4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Spend4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/spend-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/spend/`.
