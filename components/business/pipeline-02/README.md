# Pipeline: Stage Summary

The open value, with each stage as a segment of one bar sized by value or by count.

```tsx
import { Pipeline2, pipeline2ExampleProps } from "./pipeline-02";

<Pipeline2 {...pipeline2ExampleProps} />;
```

`pipeline2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Pipeline2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/pipeline-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/pipeline/`.
