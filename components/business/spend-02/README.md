# Spend: Spend by Service

The total spent and where it's heading, with a budget bar per service and the ones over or on pace to go over.

```tsx
import { Spend2, spend2ExampleProps } from "./spend-02";

<Spend2 {...spend2ExampleProps} />;
```

`spend2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Spend2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/spend-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/spend/`.
