# Usage Meter: Storage Breakdown

Storage by category as one segmented bar, with each category's size and share, and the space that's free.

```tsx
import { UsageMeter5, usageMeter5ExampleProps } from "./usage-meter-05";

<UsageMeter5 {...usageMeter5ExampleProps} />;
```

`usageMeter5ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `UsageMeter5Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/usage-meter-05
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/usage-meter/`.
