# Usage Meter: Storage Ring

Storage used as a ring in its status colour, with the space that's free.

```tsx
import { UsageMeter2, usageMeter2ExampleProps } from "./usage-meter-02";

<UsageMeter2 {...usageMeter2ExampleProps} />;
```

`usageMeter2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `UsageMeter2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/usage-meter-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/usage-meter/`.
