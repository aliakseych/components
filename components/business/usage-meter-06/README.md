# Usage Meter: Plan Limits

Every limit on a plan, flagging the ones nearly reached and prompting an upgrade.

```tsx
import { UsageMeter6, usageMeter6ExampleProps } from "./usage-meter-06";

<UsageMeter6 {...usageMeter6ExampleProps} />;
```

`usageMeter6ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `UsageMeter6Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/usage-meter-06
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/usage-meter/`.
