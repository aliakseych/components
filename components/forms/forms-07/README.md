# Forms: Number and Money

Numbers with their unit or currency, formatted when you leave the field, and minus and plus for a count.

```tsx
import { Forms7, forms7ExampleProps } from "./forms-07";

<Forms7 {...forms7ExampleProps} />;
```

`forms7ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Forms7Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/forms-07
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/forms/`.
