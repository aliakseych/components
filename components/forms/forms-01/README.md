# Forms: Sections

Fields grouped into titled sections, with a save bar that counts unsaved changes.

```tsx
import { Forms1, forms1ExampleProps } from "./forms-01";

<Forms1 {...forms1ExampleProps} />;
```

`forms1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Forms1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/forms-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/forms/`.
