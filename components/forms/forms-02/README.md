# Forms: Sheet

A record created in a panel that slides in from the side.

```tsx
import { Forms2, forms2ExampleProps } from "./forms-02";

<Forms2 {...forms2ExampleProps} />;
```

`forms2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Forms2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/forms-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/forms/`.
