# Cascader

Compose `Cascader`, `CascaderTrigger`, `CascaderContent`, `CascaderPanel`, `CascaderNav`, `CascaderList` and `CascaderItems`; data is `CascaderNode[]` (or flat with a parent pointer). Modes: drill, columns, tree.

## Origin

ByosUI cascader on Base UI combobox. Spinner and scroll-area base-ui parts are local.
