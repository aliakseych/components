# Forms: Choice Cards

One or several options drawn as cards, each with its price and a line of detail.

```tsx
import { Forms6, forms6ExampleProps } from "./forms-06";

<Forms6 {...forms6ExampleProps} />;
```

`forms6ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Forms6Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/forms-06
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/forms/`.
