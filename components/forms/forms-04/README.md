# Forms: Inline Edit

One value edited at a time, in place.

```tsx
import { Forms4, forms4ExampleProps } from "./forms-04";

<Forms4 {...forms4ExampleProps} />;
```

`forms4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Forms4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/forms-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/forms/`.
