# Forms: Multi-select

Several values picked from a searchable list, each shown as a chip you can remove.

```tsx
import { Forms5, forms5ExampleProps } from "./forms-05";

<Forms5 {...forms5ExampleProps} />;
```

`forms5ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Forms5Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/forms-05
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/forms/`.
