# Combobox

A searchable dropdown for choosing from a list, with an option to create new values.

## Exports

`Combobox`, `ComboboxTrigger`, `ComboboxContent`, `ComboboxInput`, `ComboboxList`, `ComboboxEmpty`, `ComboboxGroup`, `ComboboxItem`, `ComboboxSeparator`, `ComboboxCreateNew`

Props are typed in `index.tsx`. See `demos/` for a complete example.

## Origin

From [Kibo UI](https://www.kibo-ui.com) (MIT). Copy this folder with the `use-component` skill, which also installs its dependencies.
