# Context Usage

A small ring showing how much of an AI model's context is used, with a hover card of token details.

See `demos/default.tsx` for a complete example.

## Changes from AI Elements

Restyled to match shadcn's hover card and progress: `text-sm` type in the app font rather than monospace, tabular numbers, `p-4` spacing and a `w-64` card.

From AI Elements (ai-sdk.dev/elements).
