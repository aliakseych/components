# Calendar: Planner

A content calendar that switches between month and week, with each calendar shown or hidden from the sidebar.

```tsx
import { Calendar3, calendar3ExampleProps } from "./calendar-03";

<Calendar3 {...calendar3ExampleProps} />;
```

`calendar3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Calendar3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/calendar-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/calendar/`.
