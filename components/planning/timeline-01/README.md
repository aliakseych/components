# Timeline: Roadmap

Projects grouped by team, each a bar from start to end filled to its progress, with a today line.

```tsx
import { Timeline1, timeline1ExampleProps } from "./timeline-01";

<Timeline1 {...timeline1ExampleProps} />;
```

`timeline1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Timeline1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/timeline-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/timeline/`.
