# Gantt Scheduler

Compound gantt: `Gantt` provider, `GanttNav`, `GanttScaleSwitcher`, `GanttView`. Rows are resources/nodes, bars are events with optional dependencies, baselines and milestones.

## Origin

ByosUI gantt. Sits next to the simpler Kibo-based `planning/gantt`. Base-ui shadcn parts ship as local `base-*.tsx` files.
