# Calendar: Month

A month of team events, launches, travel and holidays, with the selected day's events listed beside the grid.

```tsx
import { Calendar1, calendar1ExampleProps } from "./calendar-01";

<Calendar1 {...calendar1ExampleProps} />;
```

`calendar1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Calendar1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/calendar-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/calendar/`.
