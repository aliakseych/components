# Timeline: Release Cadence

Every release on one line, sized by major, minor and patch, with the median gap and when the next one is due.

```tsx
import { Timeline3, timeline3ExampleProps } from "./timeline-03";

<Timeline3 {...timeline3ExampleProps} />;
```

`timeline3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Timeline3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/timeline-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/timeline/`.
