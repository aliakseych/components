# Schedule: Agenda

Upcoming events grouped by day, with the event in progress marked.

```tsx
import { Schedule1, schedule1ExampleProps } from "./schedule-01";

<Schedule1 {...schedule1ExampleProps} />;
```

`schedule1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Schedule1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/schedule-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/schedule/`.
