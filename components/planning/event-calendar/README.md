# Event Calendar

Compound calendar: `EventCalendar` provider, `EventCalendarNav` / `EventCalendarToolbar` controls and `EventCalendarContent` view. Pass `defaultEvents`, `defaultView`, `resources`, `locale`, `i18n`, `timeZone`, `interactions` and `renderEvent`.

## Origin

ByosUI event-calendar. The base-ui shadcn parts it needs ship as local `base-*.tsx` files, so the Radix `components/ui` is untouched.
