# Schedule: Deadlines

Deadlines and renewals in date order, each with a countdown coloured by how close it is.

```tsx
import { Schedule3, schedule3ExampleProps } from "./schedule-03";

<Schedule3 {...schedule3ExampleProps} />;
```

`schedule3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Schedule3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/schedule-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/schedule/`.
