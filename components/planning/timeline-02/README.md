# Timeline: Milestones

A launch plan on a rail, led by the days until the next milestone, with how soon or how late each one is.

```tsx
import { Timeline2, timeline2ExampleProps } from "./timeline-02";

<Timeline2 {...timeline2ExampleProps} />;
```

`timeline2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Timeline2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/timeline-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/timeline/`.
