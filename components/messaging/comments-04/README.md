# Comments: Ticket

A support ticket's conversation, with replies emailed to the customer and internal notes only the team sees.

```tsx
import { Comments4, comments4ExampleProps } from "./comments-04";

<Comments4 {...comments4ExampleProps} />;
```

`comments4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Comments4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/comments-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/comments/`.
