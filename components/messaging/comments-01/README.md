# Comments: Discussion

Threads with replies, reactions and a resolved thread, and a box to start a new one.

```tsx
import { Comments1, comments1ExampleProps } from "./comments-01";

<Comments1 {...comments1ExampleProps} />;
```

`comments1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Comments1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/comments-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/comments/`.
