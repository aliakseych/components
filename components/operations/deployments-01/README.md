# Deployments: Recent Deployments

The latest builds with their commit, environment, author, duration and status.

```tsx
import { Deployments1, deployments1ExampleProps } from "./deployments-01";

<Deployments1 {...deployments1ExampleProps} />;
```

`deployments1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Deployments1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/deployments-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/deployments/`.
