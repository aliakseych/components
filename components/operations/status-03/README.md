# Status: Incident

An active incident with its severity, the services it affects and its updates, newest first.

```tsx
import { Status3, status3ExampleProps } from "./status-03";

<Status3 {...status3ExampleProps} />;
```

`status3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Status3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/status-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/status/`.
