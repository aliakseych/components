# Tree

An animated, expandable tree with lines, icons and single or multiple selection.

## Exports

`TreeProvider`, `TreeView`, `TreeNode`, `TreeNodeTrigger`, `TreeLines`, `TreeNodeContent`, `TreeExpander`, `TreeIcon`, `TreeLabel`

Props are typed in `index.tsx`. See `demos/` for a complete example.

## Origin

From [Kibo UI](https://www.kibo-ui.com) (MIT). Copy this folder with the `use-component` skill, which also installs its dependencies.
