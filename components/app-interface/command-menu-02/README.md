# Command Menu: Record Search

Recently viewed records before you type, then customers and orders fetched as you type.

```tsx
import { CommandMenu2, commandMenu2ExampleProps } from "./command-menu-02";

<CommandMenu2 {...commandMenu2ExampleProps} />;
```

`commandMenu2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `CommandMenu2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/command-menu-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/command-menu/`.
