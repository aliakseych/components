# Settings: Integrations

Connected and available integrations, with what they do and the ones that need reconnecting.

```tsx
import { Settings4, settings4ExampleProps } from "./settings-04";

<Settings4 {...settings4ExampleProps} />;
```

`settings4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Settings4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/settings-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/settings/`.
