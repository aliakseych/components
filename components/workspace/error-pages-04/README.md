# Error Pages: Maintenance

What's being done, when it'll be back, the latest updates and an email when it's over.

```tsx
import { ErrorPages4, errorPages4ExampleProps } from "./error-pages-04";

<ErrorPages4 {...errorPages4ExampleProps} />;
```

`errorPages4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `ErrorPages4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/error-pages-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/error-pages/`.
