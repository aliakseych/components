# Settings: Danger Zone

Transferring, archiving and deleting the workspace.

```tsx
import { Settings6, settings6ExampleProps } from "./settings-06";

<Settings6 {...settings6ExampleProps} />;
```

`settings6ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Settings6Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/settings-06
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/settings/`.
