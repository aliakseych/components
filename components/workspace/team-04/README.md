# Team: On Call

Who is on call now and until when, who is next, and the rest of the rota.

```tsx
import { Team4, team4ExampleProps } from "./team-04";

<Team4 {...team4ExampleProps} />;
```

`team4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Team4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/team-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/team/`.
