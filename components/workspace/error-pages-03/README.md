# Error Pages: Something Went Wrong

Try again, an error ID to copy for support, and the technical details folded away.

```tsx
import { ErrorPages3, errorPages3ExampleProps } from "./error-pages-03";

<ErrorPages3 {...errorPages3ExampleProps} />;
```

`errorPages3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `ErrorPages3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/error-pages-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/error-pages/`.
