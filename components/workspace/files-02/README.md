# Files: File Table

Files with their type, owner, last change and size, to search, filter, sort, download or delete.

```tsx
import { Files2, files2ExampleProps } from "./files-02";

<Files2 {...files2ExampleProps} />;
```

`files2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Files2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/files-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/files/`.
