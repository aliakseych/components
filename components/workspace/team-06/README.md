# Team: Share

People invited to a dashboard with view or edit access, and who the link works for.

```tsx
import { Team6, team6ExampleProps } from "./team-06";

<Team6 {...team6ExampleProps} />;
```

`team6ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Team6Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/team-06
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/team/`.
