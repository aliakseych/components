# Activity Feed: Record History

The history of one record as a timeline, oldest first, with each change from one value to the next and comments quoted in full.

```tsx
import { ActivityFeed2, activityFeed2ExampleProps } from "./activity-feed-02";

<ActivityFeed2 {...activityFeed2ExampleProps} />;
```

`activityFeed2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `ActivityFeed2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/activity-feed-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/activity-feed/`.
