# Activity Feed: Weekly Digest

A week of activity as daily bars with the busiest day labelled, then the count of each kind of activity and the most active people.

```tsx
import { ActivityFeed4, activityFeed4ExampleProps } from "./activity-feed-04";

<ActivityFeed4 {...activityFeed4ExampleProps} />;
```

`activityFeed4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `ActivityFeed4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/activity-feed-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/activity-feed/`.
