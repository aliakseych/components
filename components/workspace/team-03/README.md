# Team: Who's Online

How many people are online, with their avatars, and the team split by presence.

```tsx
import { Team3, team3ExampleProps } from "./team-03";

<Team3 {...team3ExampleProps} />;
```

`team3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Team3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/team-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/team/`.
