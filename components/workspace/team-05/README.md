# Team: Roles and Permissions

A grid of permissions by role, with changes highlighted until they're saved or discarded.

```tsx
import { Team5, team5ExampleProps } from "./team-05";

<Team5 {...team5ExampleProps} />;
```

`team5ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Team5Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/team-05
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/team/`.
