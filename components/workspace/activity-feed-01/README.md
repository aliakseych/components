# Activity Feed: Recent Activity

What people did across a workspace, newest first and grouped by day.

```tsx
import { ActivityFeed1, activityFeed1ExampleProps } from "./activity-feed-01";

<ActivityFeed1 {...activityFeed1ExampleProps} />;
```

`activityFeed1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `ActivityFeed1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/activity-feed-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/activity-feed/`.
