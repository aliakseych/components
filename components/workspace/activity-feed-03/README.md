# Activity Feed: Notifications

Notifications with All, Mentions and Unread tabs, marked read one at a time or all at once.

```tsx
import { ActivityFeed3, activityFeed3ExampleProps } from "./activity-feed-03";

<ActivityFeed3 {...activityFeed3ExampleProps} />;
```

`activityFeed3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `ActivityFeed3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/activity-feed-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/activity-feed/`.
