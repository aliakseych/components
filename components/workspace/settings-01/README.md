# Settings: Members

Members and pending invites with their roles, and seats counted against the plan.

```tsx
import { Settings1, settings1ExampleProps } from "./settings-01";

<Settings1 {...settings1ExampleProps} />;
```

`settings1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Settings1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/settings-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/settings/`.
