# Team: Workload

The points assigned against the team's capacity, then each person on a shared scale, with anyone over capacity first.

```tsx
import { Team2, team2ExampleProps } from "./team-02";

<Team2 {...team2ExampleProps} />;
```

`team2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Team2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/team-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/team/`.
