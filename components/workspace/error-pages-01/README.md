# Error Pages: Not Found

The path that wasn't found, a search, and the places people usually look for.

```tsx
import { ErrorPages1, errorPages1ExampleProps } from "./error-pages-01";

<ErrorPages1 {...errorPages1ExampleProps} />;
```

`errorPages1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `ErrorPages1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/error-pages-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/error-pages/`.
