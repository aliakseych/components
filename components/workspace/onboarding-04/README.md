# Onboarding: Personalise

A role, a team size and up to three goals, turned into the dashboards set up for them.

```tsx
import { Onboarding4, onboarding4ExampleProps } from "./onboarding-04";

<Onboarding4 {...onboarding4ExampleProps} />;
```

`onboarding4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Onboarding4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/onboarding-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/onboarding/`.
