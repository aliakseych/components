# Team: Member List

Members with their role, presence and when they were last active.

```tsx
import { Team1, team1ExampleProps } from "./team-01";

<Team1 {...team1ExampleProps} />;
```

`team1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Team1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/team-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/team/`.
