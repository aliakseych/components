# Record Detail: Ticket

A description, activity with comments, a comment box, and properties such as priority, assignee and labels.

```tsx
import { RecordDetail3, recordDetail3ExampleProps } from "./record-detail-03";

<RecordDetail3 {...recordDetail3ExampleProps} />;
```

`recordDetail3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `RecordDetail3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/record-detail-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/record-detail/`.
