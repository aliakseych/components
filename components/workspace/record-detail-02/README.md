# Record Detail: Order

Line items with totals, a timeline of what happened, the customer, and shipping and payment.

```tsx
import { RecordDetail2, recordDetail2ExampleProps } from "./record-detail-02";

<RecordDetail2 {...recordDetail2ExampleProps} />;
```

`recordDetail2ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `RecordDetail2Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/record-detail-02
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/record-detail/`.
