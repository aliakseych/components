# Record Detail: Customer

Headline numbers, recent orders, contact details and notes.

```tsx
import { RecordDetail1, recordDetail1ExampleProps } from "./record-detail-01";

<RecordDetail1 {...recordDetail1ExampleProps} />;
```

`recordDetail1ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `RecordDetail1Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/record-detail-01
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/record-detail/`.
