# Emails: Payment Failed

The amount due on the panel with the card and the bank's reason, Update card, and when the card is tried again before the plan stops.

```tsx
import { Email4, email4ExampleProps } from "./email-04";

<Email4 {...email4ExampleProps} />;
```

`email4ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Email4Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/email-04
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/email/`.
