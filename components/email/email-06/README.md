# Emails: Usage Alert

How much of the limit is used, with a meter on the panel, when it resets, and which projects used it.

```tsx
import { Email6, email6ExampleProps } from "./email-06";

<Email6 {...email6ExampleProps} />;
```

`email6ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Email6Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/email-06
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/email/`.
