# Emails: Trial Ending

The days left on the panel with Add a card, and what changes on the plan the workspace moves to without one.

```tsx
import { Email5, email5ExampleProps } from "./email-05";

<Email5 {...email5ExampleProps} />;
```

`email5ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Email5Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/email-05
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/email/`.
