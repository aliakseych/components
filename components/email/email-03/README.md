# Emails: Receipt

The amount paid on the panel, the lines and tax that add up to it, and links to the invoice and billing.

```tsx
import { Email3, email3ExampleProps } from "./email-03";

<Email3 {...email3ExampleProps} />;
```

`email3ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Email3Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/email-03
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/email/`.
