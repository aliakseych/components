# Emails: Welcome

The first step on the panel with its button, the steps after it, and who reads a reply.

```tsx
import { Email7, email7ExampleProps } from "./email-07";

<Email7 {...email7ExampleProps} />;
```

`email7ExampleProps` holds sample data. Pass your own props in its shape; the types are exported as `Email7Props`.

## Install in an app

```bash
npx shadcn@latest add @dashboardblocks/email-07
```

The CLI copies the block, the dashboardblocks parts it uses and the shadcn parts it needs. The source in this library lives under `components/dashboardblocks/email/`.
