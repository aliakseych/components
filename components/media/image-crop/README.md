# Image Crop

An image cropper with a draggable selection, reset and apply, which returns the cropped image as a data URL.

## Exports

`ImageCrop`, `ImageCropContent`, `ImageCropApply`, `ImageCropReset`, `Cropper`

Props are typed in `index.tsx`. See `demos/` for a complete example.

## Origin

From [Kibo UI](https://www.kibo-ui.com) (MIT). Copy this folder with the `use-component` skill, which also installs its dependencies.
